# Data sources and attribution

## AI4I 2020 Predictive Maintenance Dataset

This project uses the AI4I 2020 Predictive Maintenance Dataset from the UCI
Machine Learning Repository.

- Dataset: https://archive.ics.uci.edu/dataset/601/ai4i%2B2020%2Bpredictive%2Bmaintenance%2Bda
- DOI: https://doi.org/10.24432/C5HS5C
- Citation: AI4I 2020 Predictive Maintenance Dataset [Dataset]. (2020). UCI
  Machine Learning Repository.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).
- Nature: synthetic data generated to reflect predictive-maintenance scenarios.

The archive is excluded from Git. Dataset terms require attribution when
sharing or adapting its contents. This project is independent and is not
endorsed by UCI.
